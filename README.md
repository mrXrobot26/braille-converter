# نص برايل (NassBraille)

برنامج ويندوز بيحوّل المذكرات (PDF أو Word) لملف **Word** وملف **TXT** فيهم الكلام المطبوع بس، بنفس الترتيب ومن غير صور، عشان يتقري على جهاز برايل زي HumanWare BrailleOne. البرنامج بيشتغل **من غير إنترنت**.

## الاستخدام
1. افتح `NassBraille.exe`.
2. دوس «اختار ملف»، أو اسحب الملف على البرنامج.
3. شاشة المراجعة بتعرض صورة كل صفحة جنب الكلام اللي طلع منها:
   - الأماكن المشكوك فيها متلونة.
   - مفتاح F8 بيروح للمشكلة اللي بعدها.
   - «اتراجعت ✓» بتعلّم على الصفحة إنها اتراجعت.
4. «حفظ الملفات»: اختار الفلاشة من القايمة، أو أي فولدر.

المراجعة بتتحفظ لوحدها في ملف `<اسم الملف>.nassbraille.json` جنب الأصل، فتقدر تقفل البرنامج وتكمل بعدين.

## الدقة المتوقعة

| نوع الملف | النتيجة |
|---|---|
| Word (docx/doc) | الكلام بالظبط |
| PDF معمول من Word أو أي برنامج كتابة | تقريبًا كل الكلام صح (اتقاس ١٠٠٪ على ملف المرجع) |
| PDF بخطوط عربي قديمة (Sultan, AGA وغيرها) | حوالي ٩٧–٩٨٪ من الكلام، والباقي غالبًا كلام جوه صور |
| أغلفة وصور فيها كلام، أو PDF متصور سكانر | مش هيطلع من غير إنترنت، والتقرير بيقول عليها |

نصيحة: لو تقدروا تاخدوا ملف Word الأصلي من المدرس، ده أضمن حاجة.

## للمطورين
```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pytest tests -q                  # اختبارات
.venv\Scripts\python -m nassbraille.eval <file.pdf> <gold_dir>   # قياس الدقة قدام نسخة متراجعة
.venv\Scripts\python -m nassbraille.cli <files...> -o <out>     # تحويل من سطر الأوامر
.venv\Scripts\python app.py                              # الواجهة
powershell -ExecutionPolicy Bypass -File build.ps1       # بناء dist\NassBraille
```

### إزاي محرك الـPDF بيشتغل (`nassbraille/pdf/`)
- **`device.py`**: بيسجّل اللي MuPDF بيرسمه على الصفحة: الحروف وخطوطها، والصور، والـclip، ومكان كل حاجة في هيكل المستند (struct tree)، والـ/ActualText.
- **`fonts.py` و`legacy.py` و`decide.py`**: لكل خط فيه قرايتين: الـToUnicode، والقراية من الخط نفسه (الـcmap، وأسماء الحروف، والـGSUB، وجدول الخطوط العربي القديمة). البرنامج بيختار لكل خط القراية اللي بتدّي عربي سليم.
- **`lines.py`**: بيبني السطور من أماكن الحروف: الترتيب من اليمين للشمال، ورجوع الأرقام والإنجليزي لترتيبهم، والمسافات، وقلب الأقواس.
- **`tagged.py`**: لو الملف فيه هيكل، الترتيب بيمشي على الهيكل، والبراويز والجداول بتتعامل لوحدها. وفيه كمان النص المخفي اللي Word بيحطه للسطور اللي حوّلها صور.
- **`geometric.py`**: لو الملف مالوش هيكل: الأعمدة، والفقرات، والبراويز من المستطيلات المرسومة، وشيل الهيدر والفوتر.
- **`headings.py`**: بيعرف العناوين من شكل الخط لما مالهاش علامة عنوان.

ملفات المرجع في `tests/fixtures/` محلية بس، وماينفعش تتوزع.
